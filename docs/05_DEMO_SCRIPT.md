# LifeOps AI — Judge Demo Script

## 90-second demo

### 0–10 sec — Problem
“Important actions are hidden inside documents and messages. People don't just need summaries; they need to know what to do next.”

### 10–20 sec — Input
Upload an internship offer email or paste its text.

### 20–35 sec — Agent pipeline
Show:
Intake → Understanding → Planning → Verification → Action

Explain:
“The system doesn't simply summarize. It turns the source into structured obligations and checks whether each important claim is supported.”

### 35–50 sec — Action plan
Show:
- Sign document
- Return it
- Deadline
- Required attachment
- Priority
- Evidence

### 50–65 sec — Deadline Shield
Show deadline and prerequisite dependency.

“Missing the deadline is not the only risk. The system identifies what must happen before the deadline.”

### 65–75 sec — What-if
Ask:
“What happens if I miss the deadline?”

If source does not specify the consequence:
“The system refuses to invent one and marks it for verification.”

### 75–85 sec — Action Pack
Download .ics and JSON/Markdown export.

### 85–90 sec — Closing
“LifeOps AI turns information into an execution plan — with evidence, deadlines, dependencies, and verification.”
